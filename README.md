# 🐙 Repositório GitHub - Consulta e Integração com API v3

![Status](https://img.shields.io/badge/Status-Finalizado-green)

Este projeto tem como objetivo principal o aprimoramento prático no consumo de **APIs REST**, utilizando a API V3 do GitHub. A aplicação permite buscar e integrar dados de perfis em uma interface web simples e funcional, reforçando meus estudos para me tornar um **Desenvolvedor Full-Stack**.

## 🚀 Principais Aprendizados

O desenvolvimento deste repositório permitiu consolidar conceitos fundamentais de comunicação entre front-end e serviços externos:

- 📡 **Consumo de REST APIs**: Prática intensiva no consumo da API do GitHub, lidando com respostas JSON e tratamento de dados recebidos.
- ⚡ **JavaScript Assíncrono**: Uso de técnicas para garantir que a interface permaneça fluida enquanto os dados são recuperados do servidor.
- 🧩 **Manipulação de DOM**: Integração dinâmica dos dados do perfil (como fotos, bios e repositórios) diretamente no HTML sem recarregar a página.
- 🎨 **Estilização com Bootstrap**: Utilização do **Bootstrap** (meu padrão de design) para garantir uma interface limpa, moderna e totalmente responsiva.

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: JavaScript (ES6+).
- **Estruturação**: HTML5.
- **Design/UI**: Bootstrap 5.
- **Fonte de Dados**: GitHub API V3.
